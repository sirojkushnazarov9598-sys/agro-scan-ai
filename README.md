# AGRO SCAN AI: телефонга ўрнатиладиган илова

«Бир сурат — бир аниқ ечим!» Деҳқон баргни суратга олади, сунъий интеллект касаллик эҳтимолини аниқлайди, тавсиялар агроном тасдиқлайдиган базадан берилади.

Бу PWA: телефон бош экранига иловадек қўшилади, ўз иконкаси бор, тарих ва касалликлар китоби интернетсиз ҳам очилади. Суратни таҳлил қилиш учун интернет керак.

## Папка таркиби

```
public/            телефонга берилувчи саҳифа
  index.html       илова
  diseases.json    касалликлар ва тавсиялар базаси (шуни агроном тўлдиради)
  manifest.webmanifest, sw.js, icons/   ўрнатиш учун
api/analyze.js     сервер функцияси: суратни Claude API га юборади
vercel.json        Vercel созламалари
```

## Интернетга чиқариш (Vercel, тахминан 15 дақиқа)

1. github.com да ҳисоб очинг ва янги repository яратинг (масалан, `agro-scan-ai`). «Add file → Upload files» орқали шу папкадаги ҳамма файлларни юкланг (`public`, `api`, `vercel.json`, `package.json`).
2. vercel.com га GitHub орқали киринг. «Add New → Project» ни босиб, `agro-scan-ai` ни танланг. Framework Preset: **Other**.
3. Deploy босишдан аввал «Environment Variables» га қўшинг:
   - `ANTHROPIC_API_KEY` = Claude API калити
   - (ихтиёрий) `ANTHROPIC_MODEL` = `claude-sonnet-5-5`
4. Калитни console.anthropic.com → API Keys бўлимида оласиз. API алоҳида ҳисоб, ишлатилганига қараб пул ечилади. **Settings → Limits** да ойлик чегара қўйинг.
5. «Deploy» ни босинг. Vercel сизга `https://agro-scan-ai-xxxx.vercel.app` кўринишида ҳавола беради.

Эслатма: Vercel Hobby (бепул) режаси тижорат бўлмаган лойиҳалар учун. Танлов ва синов даври учун етади, тижоратга чиқарганда Pro режасига ўтиш керак бўлади.

## Телефонга ўрнатиш

- **Android (Chrome):** ҳаволани очинг. Тепада «Иловани ўрнатиш» тугмаси чиқади. Чиқмаса, ⋮ менюсидан «Иловани ўрнатиш» ёки «Бош экранга қўшиш» ни танланг.
- **iPhone:** ҳаволани албатта **Safari** да очинг. «Улашиш» тугмаси → «Бош экранга қўшиш».
- Плакатга қўйиш учун ҳаволадан QR-код ясанг (масалан, qrcode-monkey.com).

## Нархи ва ҳимоя

- Ҳар бир таҳлил Claude API га битта сурат юборади. Аниқ нархни console.anthropic.com → Usage да кўринг: аввал 50–100 та таҳлил қилиб, битта таҳлил нархини ўлчанг ва шунга қараб ойлик чегара қўйинг.
- API калити фақат Vercel муҳитида туради, `index.html` да йўқ.
- Ҳавола билан кирган ҳар ким таҳлил қила олади. Серверда IP бўйича соатига 30 та таҳлил чегараси бор, лекин бу тўлиқ ҳимоя эмас. Фойдаланувчи кўпайса, рўйхатдан ўтиш қўшиш керак.
- Суратлар серверда сақланмайди, фақат таҳлил учун Claude API га юборилади. Деҳқонларга шуни айтиб қўйинг.

## Базани янгилаш

`public/diseases.json` да ҳар бир касалликнинг аломатлари (`signs`) ва агротехник чоралари (`actions`) бор. Агроном текширгач, матнларни тузатиб, `"approved": true` қилинг: сариқ «қоралама» огоҳлантириши йўқолади. Кимёвий воситалар бўлими ҳозир саҳифада «агроном тасдиқлайди» деб туради, тасдиқланган рўйхат тайёр бўлганда уни базага қўшиш керак.

## Компьютерда синаш

Node.js ўрнатилган бўлса: папкада `npx vercel dev` ёзинг. `.env.local` файлига `ANTHROPIC_API_KEY=...` қўйинг.

## Кейинги қадам: Google Play

Ҳавола тайёр бўлгач, pwabuilder.com га киритсангиз, Android пакети (AAB) ясайди. Google Play га чиқариш учун Google Play Console ҳисоби керак (бир марталик тўлов).
